## Proyectos destacados

### [Catastro Municipal](https://github.com/uniqueP4ris/Catastro-Municipal)
Base de datos en **MySQL 8** para administrar el catastro de un municipio: viviendas, propietarios, familias y zonas urbanas.
- Modelo entidad-relación, grafo relacional y diccionario de datos.
- 7 tablas relacionadas con llaves foráneas y 23 vistas SQL para consultas y validación de datos.
- Script de instalación, datos de prueba ficticios y README con ejemplos de consultas.

### [Ideas](https://github.com/uniqueP4ris/Ideas)
Aplicación web para registrar ideas de proyectos con título, descripción, categoría, estado (registrada, en revisión, aprobada o rechazada) y observaciones.
- Hecha con **PHP, Laravel y Filament**.
- Migraciones, relación categorías–ideas, eliminación lógica y panel de estadísticas.
